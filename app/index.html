DevOps Lab · Demo application

Hello, world!

This is a small Hello World web application. It displays a simple web page and demonstrates how an application is packaged into a container and prepared for deployment.

What's inside

Static web page

An HTML page describing the application. It needs no JavaScript or server-side logic.

Nginx in a container

Nginx serves the page on port 8080 and runs as an unprivileged user.

Ready to deploy

A Helm chart configures the application and its security settings for Kubernetes.

A simple application example — from an HTML page to a container deployment.
